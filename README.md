# 📝 StudyFlow (ex-Пишу24/7) — White-Label платформа и Telegram-бот для заказа учебных и экспертных работ с превью до оплаты

Готовый к продакшну **open-source движок** для приёма, выполнения и оплаты заказов на текстовые, аналитические и учебные работы (курсовые, рефераты, научные статьи, конспекты, презентации) через **Telegram-бота + веб-кабинеты + встроенный лендинг**.

> 💡 **История проекта:** Изначально платформа разрабатывалась и работала в продакшне под брендом **«Пишу24/7»**. Теперь весь код выложен в открытый доступ как **White-Label решение**: вы просто вписываете своё название, имя бота, реквизиты и ключи оплаты в `.env` — и получаете готовый сайт, юридические страницы, Telegram-бота и два веб-кабинета (`/admin` и `/editor`).

---

## 🔥 Главные фичи

1. **«Сначала смотришь — потом платишь» (Защищённое PDF-превью):**
   - Редактор загружает готовый `.docx`, `.pptx` или `.pdf`.
   - Система автоматически конвертирует документ в PDF, накладывает диагональный водяной знак (`ОПЛАТИТЕ ДЛЯ ПОЛУЧЕНИЯ · Заказ #N`) и **растеризует страницы в пиксели** (`services/watermark.py` на базе LibreOffice + PyMuPDF).
   - В превью **нет текстового слоя** — скопировать текст или удалить водяной знак в PDF-редакторе невозможно.
   - Сразу после оплаты робот автоматически присылает клиенту чистый исходный файл (`.docx` / `.pptx`).

2. **Три роли из коробки (и в Telegram, и в вебе):**
   - 👨‍🎓 **Клиент (Студент):** пошаговый бриф в боте, торг по цене, получение превью, оплата, до 2 бесплатных доработок, реферальный кабинет (`200 ₽` за первый заказ друга + `5%` с последующих).
   - ✍️ **Редактор (Исполнитель):** работает либо прямо в Telegram-боте, либо через удобный веб-кабинет `/editor` (загрузка финалов, генерация 4 вариантов вотермарки, отправка превью и правок).
   - 👑 **Администратор (Владелец):** управляет заказами, ценами, пользователями, возвратами, реферальными выплатами и аудитом через бот или веб-панель `/admin` (вход по одноразовому коду в Telegram).

3. **Легальная оплата по 54-ФЗ (Робокасса + «Мой налог» / НПД):**
   - Встроенная интеграция с **Робокассой** (`services/payment.py`): формирование фискального чека `Receipt` (`tax: none`, полная оплата услуги), короткие ссылки `/pay/{id}` и автоматическая выдача чистого файла по вебхуку `/robokassa/result`.
   - Поддержка тестового режима (`ROBOKASSA_IS_TEST=true`) для проверки всей воронки без реальных списаний.

4. **White-Label лендинг и документы из `.env`:**
   - Встроенный премиальный лендинг (`/`), Публичная оферта (`/oferta`), Политика конфиденциальности (`/privacy`) и Контакты (`/contacts`) автоматически подтягивают ваше название (`BRAND_NAME`), `@BOT_USERNAME`, ФИО, ИНН и email из `.env`.
   - В папке `landing/tilda-t123-block.html` также лежит готовый блок для вставки в Tilda (`T123`), если вы хотите захостить витрину на Тильде.

## 🗺 Воронка статусов заказа

```text
FILLING → PENDING → IN_WORK → EDITING → PREVIEW_SENT → AWAITING_PAYMENT → DONE
                                                                          ↓
                                                                CANCELLED / REFUNDED
```

1. **Бриф (`FILLING → PENDING`):** Клиент выбирает тип работы, тему, предмет, объём, дедлайн и прикрепляет методички. Бот рассчитывает стартовую вилку цены (`services/pricing.py`).
2. **Согласование цены (`PENDING → IN_WORK`):** Админ подтверждает или корректирует цену. Клиент может согласиться (✅), предложить свою цену (💬 торг) или отменить (❌).
3. **Работа и превью (`EDITING → PREVIEW_SENT`):** Редактор загружает готовые файлы → генерируется растеризованный PDF с водяным знаком → уходит клиенту вместе с кнопкой оплаты.
4. **Оплата и выдача (`AWAITING_PAYMENT → DONE`):** Клиент указывает email для чека 54-ФЗ, оплачивает по ссылке → Робокасса стучится в `/robokassa/result` → бот мгновенно отправляет чистый файл без водяного знака и начисляет бонус рефереру.

## 🚀 Быстрый старт (за 3 минуты)

### Вариант А: Запуск в одну команду через Docker Compose (Рекомендуется)

Внутри Docker-образа уже настроены Python 3.12, LibreOffice (Writer + Impress) и кириллические шрифты для генерации водяных знаков.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/grisha123invent-official/studyflow-bot.git
cd studyflow-bot

# 2. Создайте .env и впишите свой BOT_TOKEN, ADMIN_TG_ID и название бренда
cp .env.example .env
nano .env

# 3. Запустите бота и веб-платформу
docker compose up -d --build
```

После запуска откройте:
- 🌐 **Лендинг:** `http://localhost:8081/`
- 📄 **Оферта / Политика / Контакты:** `http://localhost:8081/oferta`, `/privacy`, `/contacts`
- 🔐 **Админ-панель:** `http://localhost:8081/admin` (авторизация по OTP-коду в Telegram)
- ✍️ **Кабинет редактора:** `http://localhost:8081/editor`

---

### Вариант Б: Локальный запуск без Docker (macOS / Linux)

```bash
# 1. Создайте виртуальное окружение и установите зависимости
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Для конвертации .pptx и точной вёрстки .docx рекомендуется установить LibreOffice:
# macOS: brew install --cask libreoffice
# Ubuntu: sudo apt install libreoffice-writer libreoffice-impress fonts-dejavu

# 2. Заполните .env
cp .env.example .env

# 3. Запустите Telegram-бота (в первом терминале)
python main.py

# 4. Запустите веб-платформу и лендинг (во втором терминале)
uvicorn web.main:app --host 127.0.0.1 --port 8081 --reload
```

## ⚙️ Настройка под себя (`.env`)

Все персональные настройки вынесены в `.env` (см. подробный шаблон в [`.env.example`](.env.example)):

| Переменная | Описание | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен бота от `@BotFather` | `123456:ABC-DEF...` |
| `BOT_USERNAME` | Username бота без `@` (для кнопок на сайте и в оферте) | `my_study_bot` |
| `ADMIN_TG_ID` | Ваш числовой Telegram ID (узнать у `@userinfobot`) | `123456789` |
| `EDITOR_TG_ID` | Telegram ID редактора (можно также назначить из админки) | `987654321` |
| `BRAND_NAME` | Название вашего сервиса (на сайте, в админке и в боте) | `StudyFlow` |
| `PUBLIC_URL` | Публичный домен вашего сайта (для ссылок `/pay` и `/oferta`) | `https://example.com` |
| `SUPPORT_EMAIL` | Email поддержки (для сайта, оферты и чеков) | `support@example.com` |
| `OWNER_NAME` | ФИО самозанятого / ИП для футера сайта и оферты | `Иванов Иван Иванович` |
| `OWNER_INN` | ИНН исполнителя для оферты и подвала сайта | `000000000000` |
| `OWNER_CITY` | Город для шапки публичной оферты | `Москва` |
| `WATERMARK_TEXT` | Текст водяного знака на PDF-превью | `ОПЛАТИТЕ ДЛЯ ПОЛУЧЕНИЯ` |

### Подключение оплаты (Робокасса)
1. Зарегистрируйте магазин в [Робокассе](https://robokassa.com/) (доступно для самозанятых НПД, ИП и ООО).
2. В разделе **Технические настройки** магазина укажите:
   - **Алгоритм расчёта хеша:** `SHA256`
   - **Result URL:** `https://<ваш-домен>/robokassa/result` (метод `POST`)
3. Скопируйте логин магазина, пароли `#1` и `#2` (сначала тестовые при `ROBOKASSA_IS_TEST=true`, затем боевые при `ROBOKASSA_IS_TEST=false`) в `.env`.

## 🗂 Структура проекта

```text
├── main.py                 # Точка входа Telegram-бота + сервер вебхуков Робокассы (:8080)
├── config.py               # Загрузка и валидация настроек из .env
├── bot/                    # Логика Telegram-бота (aiogram 3.26)
│   ├── handlers/           # Хендлеры ролей: student.py, editor.py, admin.py
│   ├── keyboards/          # Inline и Reply клавиатуры
│   ├── states/             # FSM-состояния оформления заказа, правок и оплаты
│   └── middlewares.py      # Авторизация и определение ролей пользователей
├── web/                    # Веб-платформа (FastAPI + Jinja2 + Tailwind)
│   ├── main.py             # FastAPI-приложение (:8081): лендинг, /pay/{id}, /admin, /editor
│   ├── routes/             # Роуты админки и кабинета редактора
│   ├── security/           # Telegram OTP-вход, CSRF, Rate Limiting, Security Headers
│   └── templates/          # HTML-шаблоны админки и кабинета редактора
├── services/               # Бизнес-логика
│   ├── watermark.py        # Конвертация .docx/.pptx → PDF + растеризованный водяной знак
│   ├── payment.py          # Робокасса + фискальные чеки 54-ФЗ (Receipt)
│   ├── pricing.py          # Калькулятор базовой стоимости и срочности
│   └── prompt_builder.py   # Генерация ТЗ и промптов по заказу
├── db/                     # Слой базы данных (SQLAlchemy 2.0 async + aiosqlite)
│   ├── models.py           # ORM-модели: User, Order, File, Payment, ReferralBonus, AuditLog
│   └── crud.py             # Асинхронные операции с БД
├── landing/                # Встроенный лендинг, оферта, политика и блок для Tilda (T123)
├── deploy/                 # Скрипт автоустановки на Ubuntu VPS (systemd + nginx + certbot)
└── tests/                  # Автотесты (220+ тестов на pytest)
```
